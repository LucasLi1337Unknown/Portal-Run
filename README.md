# Portal Race v2

一个四人网页棋盘竞速游戏：你和 3 个“假装是真人网友”的 AI 对手比赛。

## v2 新增

- 每局随机匹配不同 AI 名字、头像风格和城市
- AI 有不同性格：competitive / chaos / chill / dramatic
- AI 每轮会根据局势说不同的话，不再固定重复
- 玩家可以真的在聊天框里发送消息，AI 会随机回应
- 更清楚的 32 格环形棋盘
- 实际网络延迟测量：部署到 GitHub Pages 后，会测量浏览器到当前网页主机的 HTTP 往返时间
- 如果直接双击 `index.html` 打开，会显示“本地模式”，因为 `file://` 没有远程服务器可以测 ping
- 同一格碰撞机制：移动后如果和其他玩家停在同一格，会把对手撞回 START
- 护盾可挡一次撞击或一次后退陷阱
- 摇到 **1** 可以再摇一次
- 传送门、前进、后退、换位、神秘事件
- 防无限循环：特殊格造成的位移不会再次触发另一张移动类特殊格

## 运行

直接打开 `index.html` 即可玩。

如果想看到真实延迟数字，建议部署到 GitHub Pages 后打开，因为延迟是“你的浏览器 ↔ 网页服务器”的网络往返时间，不是电脑本身固定存在的一个数字。

不需要 npm，不需要服务器端代码，不需要第三方库。
