# Portal Race v3

四人网页棋盘竞速游戏。你和 3 个“假装真人网友”的 AI 对手比赛。

## v3 重要更新

- 不再把所有玩家都叫 Lucas 😭
- 每次重新匹配都会为当前玩家自动生成一个临时网名，例如：
  - `NovaFox`
  - `PixelPuff`
  - `OrbitCat`
  - `MoonNoodle`
  - `TurboPanda`
- 你发送聊天消息时，也会显示这次随机生成的网名
- 重新匹配时，你和 3 个 AI 的名字都会重新生成
- 不保存真实姓名，也不需要登录

## 其他规则

- 4 人竞速
- 摇到 **1** 可以再摇一次
- 落到其他玩家同一格会把对方撞回 START
- 护盾可挡一次撞击或一次后退陷阱
- 传送门、前进、后退、换位、神秘事件
- AI 会根据局势随机聊天
- 玩家可以在聊天框里发送消息
- GitHub Pages 部署后会尝试测量浏览器到网页主机的 HTTP 往返延迟
- 特殊格造成的位移不会递归触发另一个移动类特殊格，防止无限循环

直接打开 `index.html` 就可以玩。
